Developer SDK

Browser JavaScript API

Integrate the same high-performance image conversion engine into your own client-side applications.

// Convert any standard image or Camera RAW file (Sony ARW, Canon CR2, PSD, SVG, etc.)
const result = await window.FluxWebP.convertFile(file, {
  format: "webp",           // 'webp' | 'png' | 'jpeg' | 'avif'
  quality: 82,              // 0 - 100
  preserveMetadata: true,   // Preserves camera EXIF from JPEG and RAW
  stripGps: true,           // Strips geolocation tags for privacy
  resize: {
    maxWidth: 1920,         // Optional: constrain max width
    maxHeight: 1080,        // Optional: constrain max height
    maintainAspect: true
  }
});

console.log(result);

Technical Documentation & Architecture

Universal Decoding Architecture

FluxWebP Pro leverages client-side WebAssembly, Canvas 2D, and specialized stream extractors to support professional camera files and graphic formats without a server backend.

1. Camera RAW Preview Parsing

Camera RAW files (.ARW, .CR2, .CR3, .NEF, .DNG, .RAF, .ORF, .RW2, .PEF) contain camera-calibrated JPEG preview streams generated by the camera's internal Image Signal Processor (ISP). FluxWebP Pro parses the TIFF IFDs and ISOBMFF container boxes to extract and render these previews with exact camera color profiles and EXIF metadata.

2. Photoshop Composite Engine

For Adobe Photoshop (.PSD and .PSB) files, the platform initializes the lightweight ag-psd canvas engine on demand to extract the merged composite image raster directly in browser memory.

3. Dynamic Vector Scaler

SVG vector files are inspected for viewBox and dimension attributes, then dynamically scaled up to 2400px before canvas rasterization, guaranteeing razor-sharp WebP results without raster pixelation.
