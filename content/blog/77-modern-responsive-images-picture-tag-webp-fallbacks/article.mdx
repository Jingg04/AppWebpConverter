# Modern Responsive Images: HTML5 <picture>, <source type='image/webp'>, and Fallbacks

> **Summary:** Deliver next-gen WebP and AVIF with zero fear of breaking older browsers. Master HTML5 <picture>, MIME-type negotiation, and universal fallback patterns.




## Frequently Asked Questions

### How does the browser decide which <source> to load?

The browser evaluates <code>&lt;source&gt;</code> tags from top to bottom. It chooses the FIRST source whose media query matches AND whose MIME type (e.g. image/avif or image/webp) it supports, completely ignoring all subsequent sources.

### Does a browser download both WebP and JPEG in a <picture> element?

No! Browsers download exactly ONE image file. As soon as a match is found, all other sources are discarded without wasting network bandwidth.

### Is the fallback <img> tag required inside <picture>?

Yes, absolutely mandatory. The <code>&lt;img&gt;</code> element is what actually renders the image on screen and holds the <code>alt</code>, <code>width</code>, and <code>height</code> attributes. Without it, nothing will display.
