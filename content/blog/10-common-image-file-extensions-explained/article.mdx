## Frequently Asked Questions

### What is the difference between .jpg and .jpeg?

There is zero technical difference. .jpg originated in older MS-DOS 8.3 FAT file systems that required 3-letter extensions, while .jpeg was the original 4-letter Unix standard. Both store identical JFIF/EXIF data.

### Can I simply rename an image extension from .jpg to .webp?

No! Renaming the file extension only changes the label on the outside. It does not re-encode the internal bitstream. Browsers inspect the file's binary magic bytes, so a renamed file remains an uncompressed JPEG inside.
