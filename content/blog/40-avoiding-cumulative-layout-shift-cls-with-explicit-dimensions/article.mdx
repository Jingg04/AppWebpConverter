# Avoiding Cumulative Layout Shift (CLS) with Explicit Image Width & Height Attributes

> **Summary:** Stop annoying layout jumps on page load. Discover how adding explicit width and height attributes eliminates Cumulative Layout Shift (CLS) for perfect Core Web Vitals.




## Frequently Asked Questions

### What is Cumulative Layout Shift (CLS)?

CLS is a Google Core Web Vitals metric measuring unexpected layout movements that occur while a page loads. A good CLS score is 0.1 or lower.

### How do explicit width and height attributes stop layout shifts?

Modern browsers calculate the image's aspect ratio from its HTML width and height attributes BEFORE the image file is downloaded. The browser reserves the exact vertical layout box, preventing text from jumping down when the image loads.

### Will HTML width='1200' prevent my image from being responsive?

No. As long as your CSS includes <code>max-width: 100%; height: auto;</code>, the image remains fully fluid and responsive while the browser respects the inherent aspect ratio.
