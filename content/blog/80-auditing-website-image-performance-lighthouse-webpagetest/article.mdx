## Frequently Asked Questions

### What does the Lighthouse audit 'Properly size images' mean?

This warning triggers when an image's rendered display size is significantly smaller than the downloaded natural file resolution (e.g., downloading a 3000px image to display in a 300px box). It flags wasted cellular data and recommends responsive downscaling.

### What is the difference between lab data and field data?

Lab data (Lighthouse) runs a simulated synthetic audit on a single device under throttled network conditions. Field data (Chrome User Experience Report / CrUX) records real-world performance metrics from actual visitors over the last 28 days. Google uses field data for ranking.

### Why is WebPageTest superior for debugging image waterfall delays?

WebPageTest provides frame-by-frame filmstrip video captures, connection negotiation logs, and TLS handshakes across physical devices located in actual international test locations.
