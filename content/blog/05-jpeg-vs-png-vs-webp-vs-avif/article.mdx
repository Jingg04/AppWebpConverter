### What is the fastest rule of thumb for choosing between these four formats?

Use WebP as your universal default for all web assets. Use AVIF via the <picture> tag for hero images if bandwidth is critical. Keep PNG only for source master assets. Use JPEG only when targeting legacy offline desktop software.
