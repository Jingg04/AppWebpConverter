> **Summary:** Demystify srcset and sizes once and for all. Discover how the browser uses viewport width and device pixel ratio to pick the perfect image file every time.




## Frequently Asked Questions

### What does the 'w' unit in srcset represent?

The 'w' unit represents the true physical width in pixels of the image file (e.g. 800w means the file is 800 pixels wide). It informs the browser of file dimensions before downloading.

### Why is the sizes attribute mandatory when using 'w' in srcset?

Because the browser parses images before CSS is evaluated, it doesn't know how wide the image will be on screen. The 'sizes' attribute tells the browser the image's layout width so it can calculate the optimal file to fetch.

### How does the browser pick which srcset image to download?

The browser calculates: Target Pixels = CSS Width × Device Pixel Ratio (DPR). It then downloads the smallest image from srcset that meets or exceeds that pixel count.
