## Frequently Asked Questions

### What causes the error 'HTTP 413 Payload Too Large'?

HTTP 413 occurs when the uploaded file exceeds the web server's configured maximum upload limit (e.g., <code>client_max_body_size</code> in Nginx or upload_max_filesize in PHP). Solution: Compress the image below the server threshold.

### What is a MIME type mismatch error?

A MIME mismatch happens when a file's actual internal binary signature does not match its file extension (e.g., renaming a WebP or HEIC file to <code>.jpg</code>). The server detects the discrepancy and rejects the file as a potential security risk.

### How do I compress a photo to exactly under 500KB for government/visa forms?

In FluxWebP, drop your photo, select 'Target Size: 450KB' or adjust quality to 75-80%. The engine automatically iterates compression passes until the file weight is safely beneath the ceiling.
