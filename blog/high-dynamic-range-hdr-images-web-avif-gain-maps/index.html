High Dynamic Range (HDR) Images for the Web: AVIF, Ultra HDR, and Gain Maps

D
Dr. Sarah Chen Head of Web Performance Architecture
Published: 2026-11-12 8 min read ✓ Verified Technical Review
Table of Contents

For thirty years, digital web photography has been trapped in the narrow confines of Standard Dynamic Range (SDR)—clamped to 8 bits per channel (0 to 255) and an ancient peak display brightness of 100 nits. But modern smartphone displays and OLED monitors can easily push 1,000 to 2,000 nits of peak luminance. The emergence of Ultra HDR JPEG Gain Maps and 10-bit AVIF brings genuine radiant light, sparkling reflections, and deep shadow nuance to web browsers.

The Gain Map Revolution Explained

The primary barrier to web HDR was backward compatibility: rendering an HDR photo on an SDR monitor made it look blown-out and unwatchable. Gain Maps solve this elegantly:

  1. The file contains a standard 8-bit SDR base image that displays identically on any 10-year-old browser.
  2. Embedded in metadata is a secondary low-resolution Gain Map channel.
  3. When an HDR-capable browser detects an HDR display, it executes a hardware shader that multiplies peak pixel luminance, making headlights glisten and sunsets burn with physical light.

Frequently Asked Questions

What is an HDR Gain Map in digital imaging?

A gain map is an auxiliary secondary grayscale image channel stored inside a standard JPEG or WebP file. It acts as an optical multiplier: on standard displays, the base SDR image renders normally; on HDR displays, the browser uses the gain map to boost highlights up to 1000+ nits of true physical brightness.

Why is AVIF the premier format for native 10-bit HDR?

AVIF natively supports the Rec. 2100 wide color gamut, 10-bit and 12-bit color depth, and Perceptual Quantizer (PQ) / Hybrid Log-Gamma (HLG) transfer curves without banding or artifacting.

How do you detect HDR display support in CSS?

Use the modern CSS media query: <code>@media (dynamic-range: high)</code>. This allows you to serve HDR gain map assets exclusively to compatible OLED and Apple XDR displays.
