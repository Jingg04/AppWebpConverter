Core Web Vitals

Optimizing Images for Core Web Vitals (LCP & CLS)

Updated: November 2026 • Reading time: 7 min • By FluxWebP Web Performance Team

Google uses Core Web Vitals as official ranking signals. Among the three primary metrics, Largest Contentful Paint (LCP) is overwhelmingly dominated by image loading: in over 70% of desktop and mobile web pages, the LCP element is a hero background, product photo, or featured banner.

1. Rule #1: Serve Modern Formats (WebP & AVIF)

Legacy JPEG and PNG images are too heavy for fast mobile connections. Converting uncompressed images to WebP immediately yields a 25% to 35% byte reduction without perceptual quality degradation. For hero banners, this single change can cut LCP render time by over 1.5 seconds.

2. Rule #2: Eliminate Cumulative Layout Shift (CLS)

Never serve images without explicit dimension attributes. Always include width and height attributes on your <img> tags or apply modern CSS aspect-ratio rules. This ensures the browser reserves the layout space before bytes download, eliminating jarring layout shifts.

3. Rule #3: Never Lazy-Load the LCP Element

While loading="lazy" is fantastic for images located below the fold, placing it on your primary hero banner delays image discovery until after JavaScript execution. Instead, add a <link rel="preload" as="image" href="..." fetchpriority="high"> tag in your HTML head for the LCP image.
