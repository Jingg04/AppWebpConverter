How to Add Text and Typography Overlays to Images Like a Pro

E
Elena Rostova Senior UI/UX Creative Director
Published: 2026-11-07 7 min read ✓ Verified Technical Review
Table of Contents

Placing pure white text over a high-key landscape photo or thin dark text over deep shadows creates an illegible, amateur disaster. Professional designers do not simply paste text on photos—they engineer contrast, establish typographic hierarchy, and use optical masking techniques so text remains effortless to read across all devices.

The 4 Techniques for Flawless Text Readability

1. The Gradient Scrim (Material Design Technique)

Instead of darkening the entire image, apply a smooth vertical gradient that transitions from transparent to 60% black right beneath the typography:

.hero-scrim {
  background: linear-gradient(
    to bottom,
    rgba(0, 0, 0, 0) 0%,
    rgba(0, 0, 0, 0.4) 60%,
    rgba(0, 0, 0, 0.8) 100%
  );
}

2. The Frosted Glass Backplate (Glassmorphism)

Applying a semi-transparent panel with CSS backdrop-filter blur creates an elegant modern card that guarantees readability regardless of background complexity.

3. Multi-Layer Soft Drop Shadows

Avoid harsh, 90s-style solid black drop shadows. Instead, stack two subtle shadows: one close and dark for definition, and one diffused for separation:

text-shadow: 0 2px 4px rgba(0, 0, 0, 0.6), 0 8px 16px rgba(0, 0, 0, 0.4);

Frequently Asked Questions

What is a gradient scrim and why is it better than a black box?

A scrim is a smooth semi-transparent gradient (e.g. from 60% black to 0% transparent) placed behind text. Unlike a harsh solid rectangle, a scrim subtly enhances contrast where text sits while leaving the rest of the photo completely unobstructed.

What is the WCAG contrast requirement for text over images?

WCAG 2.1 AA mandates a minimum contrast ratio of 4.5:1 for normal body text and 3:1 for large display headlines (18pt+). Busy photographic backgrounds require scrims or solid backing to meet this threshold.

How many fonts should I use on a single promotional image?

Limit yourself to two font families: one expressive display or serif typeface for the headline, and a clean, legible geometric sans-serif for secondary subheadings and call-to-actions.
